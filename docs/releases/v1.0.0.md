# Browser Privacy Core V1

V1 starts the maintained `1.x` release line with two standalone scripts: Stable for everyday compatibility and Hardened for stronger restrictions. All source and documentation remain English, licensed under GPL-3.0-or-later.

## Install or migrate

**Existing 6.x users must reinstall manually.** Version `1.0.0` is intentionally lower than `6.0.0`; userscript managers generally will not offer it as an automatic upgrade. Disable/remove old profiles, install exactly one V1 script, and reload open tabs. New V1 names/namespace create a separate install identity. A legacy guard prevents old and new cores from stacking in the same document.

- [Install Stable](https://raw.githubusercontent.com/NeonTideX/browser-privacy-core/main/dist/browser-privacy-core.stable.user.js)
- [Install Hardened](https://raw.githubusercontent.com/NeonTideX/browser-privacy-core/main/dist/browser-privacy-core.hardened.user.js)

## Changes

- Sparse block-based canvas masking avoids hashing every pixel, while preserving crop alignment, alpha, source contents, idempotence, and one-level RGB bounds.
- Module transactions roll back reversible patches when required APIs are locked; other modules continue and diagnostics report the failure.
- Frame handling is separated and mutation batches are deduplicated. A runtime shares fallback seeds with the same-origin frames it installs when storage is denied.
- Offline audio uses its captured native buffer reader; Client Hints responses use target-realm objects.
- Release source packages now include the support and community-conduct documents, plus the new benchmark and regression tests.

## Validation and limits

Passed 16 unit/build tests, 104 browser checks each in Edge and Chromium, and 102 in Firefox with two absent Client Hints probes skipped. See the [validation record](../VALIDATION.md) for versions and masking-only benchmark results.

Hardened still requires a site-provided TURN relay for WebRTC connectivity and changes offline-rendered audio data. The scripts do not provide anonymity or cover all fingerprint surfaces. Real manager injection and site/TURN behavior remain manual checks; read the [threat model](../THREAT-MODEL.md).

Release assets include both installable scripts, SHA-256 checksums, the GPL license, and a complete source archive with build instructions.
