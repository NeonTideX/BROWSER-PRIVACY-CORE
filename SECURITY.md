# Security and privacy reports

This project is a JavaScript privacy layer with documented bypasses, not an anonymity boundary. Read `docs/THREAT-MODEL.md` before interpreting a fingerprint test as a security vulnerability.

For a sensitive vulnerability, use GitHub's private vulnerability reporting if enabled on the repository. Otherwise contact the repository maintainer through a private channel listed on their GitHub profile; do not post personal data or working exploit details publicly.

Include the browser/manager versions, active profile, a minimal reproduction, expected and actual behavior, and affected surfaces. Ordinary compatibility issues can use the bug-report issue form. Remove cookies, tokens, private URLs, identifiers, and browser profile data before sharing logs.

The currently maintained source line is V6. Legacy V5.x files are not maintained here.
